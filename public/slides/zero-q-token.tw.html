Token 是什麼？為什麼 AI 按它收費？

AI学院 · 方片全员学习

帳單上寫著「按 Token 計費」，新聞裡動不動「百萬 Token」，這顆「Token」到底是個什麼東西？這一頁帶你親手把一句話切開看看。

一句話回答

Token 是 AI 讀寫文字的最小單位，大約是一小塊詞。AI 每讀一顆、每寫一顆都要消耗算力，所以按顆收費，邏輯跟計程車按里程計價一樣：跑多遠，付多少。

親手切一句話

下面有幾句現成的話，點一句試試。你會看到它被切成一顆顆彩色的小塊，每一塊就是一顆 Token，下方的計數器和帳單會即時跟著跳。

為什麼要按 Token 收費

計程車按里程計價，因為車每跑一公里都實打實地燒油。AI 同理：每讀一顆、每吐一顆 Token，機房裡的顯示卡都在做一輪運算、耗一份電。按顆數收費，是最貼近真實成本的計法。而且要注意，帳單是兩頭一起算的：

你發給它的（輸入）

你打的每一個字、貼進去的每一段資料，它都要一顆顆讀進去。讀，也要錢。

它回給你的（輸出）

它寫的每一個字也是一顆顆算出來的。寫，同樣要錢，而且單價通常更貴，因為「寫」比「讀」費勁。

所以貼一大段沒用的資料讓它讀，或者放任它寫一堆車軲轆話，兩頭都在燒錢。提示詞工程那一頁講過：提示詞裡的廢話，最後都會被一顆一顆放大成帳單。
中文更費，還是英文更費

用上面的分詞器對比一下中文句和英文句：中文常常一到兩個字就要佔一顆 Token，英文一個不短的單詞往往只佔一顆。所以表達同樣的意思，中文消耗的 Token 數常常更多。這和模型「認字」的習慣有關：它對英文見得多、切得熟，對漢字只能切得更碎。

常見誤區：字數不等於 Token 數。數字、符號、生僻詞會被切得特別碎，「#2049」這樣一個編號就佔了三顆；「今天天氣真不錯」七個字只要五顆。別拿字數直接估帳單，量級會差不少。

✅ 這一頁想和你分享的

  • Token 是計費的顆粒：AI 讀寫文字的最小單位，大約一小塊詞
  • 輸入輸出都算錢：你發的要錢，它回的也要錢，後者通常更貴
  • 同樣的意思，中文往往更費：漢字被切得更碎，顆數更多
  • 提示詞寫得精煉，就是在直接省錢：每省一顆都是真金白銀
