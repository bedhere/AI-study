## 外跳与推广

范围为实际部署源 public/，共 2,548 个 HTML 页面。技术示例中经过转义的 URL、源码字符串及开源署名保留，不误删知识内容。

清理脚本记录：484 个链接改为不可点击的来源文字，10 个原工具站推广按钮直接移除。复查静态外站导航入口为 0，原广告/JD 清理检查为 0 条残留。完整记录见 reports/outbound-cleanup.json 与 reports/outbound-links.json。

所有页面同步加载 external-platform-policy.js：同源阅读、站内练习和人格卡/证书图片下载保留；跨源链接、辅助点击、新窗口和外站表单提交受限。MutationObserver 处理后续动态插入与修改的链接。没有把所有含 URL 的课件文字当成广告，也没有声称 URL 字符串在仓库里全部消失。外部技术引用成为来源说明，用户不能从该入口直接离开本站。

发布前可运行 `npm run check:outbound`；发现静态外站入口或直接脚本外跳候选时退出失败。原有 cleanup/resources/consistency/content 检查继续执行。

## 两篇原型

| 课程 | 四格梗概 | 本地入口 |
| --- | --- | --- |
| 让 AI 按我的情况讲清楚 | 告诉起点 → 给出场景 → 出题检验 → 预警易错 | /slides/learn.html#learn-3.html |
| 它会一本正经地胡说八道 | 发现问题 → 追问出处 → 交叉核验 → 谨慎使用 | /slides/learn.html#zero-3.html |

插画采用 built-in image_gen 生成，参考素材库 tiger-teacher-pointer.webp 与 tiger-thinking-seated.webp。保持黄色、脸型、虎纹、奶油色口鼻和身体比例，改变姿态、表情和道具。完整提示词存于 comic-prompts.json。

原始 PNG 保存在工作区 outputs/comic-originals/，未覆盖生成工具原件。网页使用 public/slides/assets/comics/ 下的 WebP：personal-explanation.webp、verify-ai.webp 及各自四张切片；单篇实际加载的四张切片合计约 190—201 KiB，lazy loading，不写入 localStorage，不在访问页面时请求 AI。

漫画位于正文第一段摘要之后，替换两篇原型中重复标题的通用封面。原文交互、练习与阅读器翻页继续使用原逻辑。对“模型无法表达不确定”等过度绝对的说法作了针对性修正：模型可以表达不确定，也可能自信地出错；重要事实仍需核验。校对参考 OpenAI《Why language models hallucinate》（https://openai.com/index/why-language-models-hallucinate/）及帮助中心《Does ChatGPT tell the truth?》（https://help.openai.com/en/articles/8313428-does-chatgpt-tell-the-truth）。这些引用留在开发文档，不在课程中新增可点击外跳。

## 实现与后续批量方式

1. 用课件文件名作为稳定键，在 comic-data.js 维护四格脚本。先提取一页的核心知识，再写四个短场景，避免只改标题就复用同一套剧情。
2. 审校四格的知识准确性、原文一致性和术语；涉及模型价格、版本及能力时单独核验。不要把自动抽取的摘要当成内容定稿。
3. 使用同一组小虎角色参考与风格提示，生成静态分镜，检查角色一致性、文字、额外肢体和知识误导，再压缩入库。
4. 通过共用 lesson-comic.js/CSS 生成四格：宽屏四列，窄屏两列；每格有替代文字和独立字幕，支持键盘左右切换。
5. 动效是网页逐格高亮与轻微抬起，不是人物骨骼动画或视频。播放一次按 2.6 秒切格，可暂停；离屏、切后台或系统减少动态效果时停止播放。用户始终可以直接读完全部四格。
6. 批量生产建议使用“无字插画 + HTML 气泡/字幕”，让多语言和文案修正复用同一底图。本轮两张原型保留图内中文气泡，同时在网页提供可编辑字幕；修改图内台词仍需重新生成或替换图像。
7. 为已验收的文章逐批扩展清单。当前只接入两篇简中样例，不把 2,175 条语言记录误报为已完成漫画化。
