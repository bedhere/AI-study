# 方片学堂首页布局与滚动修订

## 本轮目标

根据 2026-11-09 的反馈，精简首屏线条、突出课程按钮、改善滚轮手感、删除重复的学习路线过场。按用户最新澄清，人格部分只改首页展示与入口：恢复参考站的丰富 AI 虎卡，继续使用原 AITI 16 题，不把界面修改扩大成内部逻辑回退。本次继续本地开发，不修改服务器。

## 最终页面顺序

1. **学堂介绍**：保留原有标题、课程说明、计数及本机学习进度；黄色「浏览课程内容」为主要操作，「继续上次学习」为次要操作。右侧保留白瓷方头机器人和鼠标跟随。
2. **方片 AI 人格测试**：保留 MBTI 式趣味体验的易懂说明，显示 16 道题、3—5 分钟、16 种 AI 人格、四维介绍及开始/图鉴按钮。预览使用参考站原图和既有 AITI 人格数据，默认 Prompt 法师；箭头可浏览全部 16 种人格的称号、关键词和宣言。
3. **实际员工学习路线**：保留 AI 起步者、业务提效者、技术共创者的三个可用课程入口。
4. **课程进度与学习工具**，以及原有完整课程目录。

删除的是中间重复标题的机器人「学习路线」过场；实际三类员工入口没有删除。原人格宣言整屏和自动课程条也已移除。

## 品牌与信息层级

- 沿用参考站的方片黄 `#FFD85F`、暖纸 `#F5F1E8`、深墨 `#303030`、白色表面和公司素材库。
- 线条只用于导航底边、两条低对比度构图线、标题短线、卡片边界与事实分隔；取消中心纵线、提示框角标、功能清单横线和右侧圆点轨。
- 主按钮使用黄色底、较大字号、箭头与轻微底部阴影；继续学习使用较安静的白底。
- 主入口直接进入 `aiti.html#quiz`，图鉴进入 `aiti.html#gallery`。首页不再指向上一轮误恢复的 32 题 MBTI 页面。
- AITI 缩写在首页解释为 AI Tiger Type Indicator。沿用原来「AI认可度 / AI使用度 / AI了解度 / 正向价值度」，不改成传统 MBTI 四维；DISC 已按 2026-11-10 最新要求从首页和 AITI 展示入口移除，旧答卷与链接仍保留兼容。
- `aiti-data.js / assets/aiti` 保持原样，题库、阈值和人格映射不变，16 张原图与素材清单 SHA256 一致。AITI 界面新增独立的虎友收集状态与卡片码，原答卷存储继续沿用，PNG 在原有结果内容后附上卡片码。

## 滚动与渲染

- 文字和测试卡使用正常文档流，由浏览器原生连续滚动；只有背景机器人画布保持 sticky。不拦截滚轮，不锁定整屏，也不以透明度隐藏正文。
- 导航高度固定，不再滚动到 40px 时折叠公告，避免 sticky 高度和画布尺寸突然变化。
- 位置和尺寸集中在 resize 测量；scroll 监听只读取 scrollY 并更新缓存目标。3D 帧不再重复读取样式、布局、写 aria/inert 或场景属性。
- 相机采用与帧率无关的指数阻尼；机器人在首屏离开时逐渐淡出，直接接测试卡，不保留空镜头停顿。
- 鼠标进入后，机器人以互动姿态大幅看向指针：合计水平约 ±54.4°、俯仰约 ±24.1°，身体仅附加约 ±5.7°；离开后平滑回到原滚动姿态。粗指针和减少动画仍不触发跟随。浏览器实测左右位置分别达到约 -48° 和 +48°，离开后回到初始姿态。
- 修正斜向跟随时的旋转耦合：头部使用 YXZ 顺序，让向右转与低头分别生效。在 1280×900 的相同右下位置，实际低头由约 7.1° 恢复至约 21.2°；四角的真实世界朝向和离开回正均已验证。新增回归检查使用实际 Three.js 世界矩阵，防止只检查角度变量却漏掉画面方向。
- 阴影改为缓存并在必要姿态变化时低频刷新；阴影贴图桌面 512、手机 256。DPR 桌面最高 1.5、手机最高 1，绘制像素预算约 250 万。
- 空闲呼吸以 30fps 绘制，滚动、指针和眨眼变化逐帧响应；画布已淡出或页面隐藏时停止连续绘制。
- 无 WebGL 时显示本地 SVG；减少动画与短横屏使用静态机器人及正常流正文，测试和课程入口仍可用。

## 验证

- **72 项回归测试通过**：课程、进度、角色路线、AITI、DISC、卡片码与收集存储、机器人四角实际朝向及渲染调度。首页预览仅展示原 AITI 人格数据；收集记录与答卷分别存储。
- 新增可读 JS 定向 lint 无问题；全量课件/脚本检查新增失败 0；本地资源缺失 0；旧推广检查剩余 0；生产构建通过。
- 实际打开 AITI 第 1/16 题，题目与原版一致；图鉴显示 16 种人格，首页预览切换到 AI 炼金术士。首页脚本不读取或写入测评记录。
- 本轮重点实测 1280×720、375×812：首页原图、人格切换、16 种图鉴和原 16 题入口正常，手机无横向溢出。机器人、正常滚动与短横屏规则沿用上一轮验证过的实现。完成后恢复默认窗口尺寸。
- 实际滚轮检查首屏到测试卡的连续衔接；课程主按钮、人格入口及员工路线保留可用。浏览器检查未发现 JS 错误/警告。
- 上述渲染预算和调度测试不代表所有设备都能达到固定帧率；没有用模拟调度次数冒充真实 FPS 测量。
