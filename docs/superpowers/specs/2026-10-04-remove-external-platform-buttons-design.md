# 删除非本地平台按钮设计

## 目标

删除课程网站中用于导航、推广或账号操作的外部平台按钮，避免访客从当前部署跳转到其他平台。课程正文、站内课程导航和参考资料链接保持不变。

## 删除范围

在所有简体中文、繁体中文、英文和韩文页面中删除以下可点击入口及其仅为该入口服务的装饰内容：

- Alice 的体验、下载和“了解更多”入口。
- GitHub 项目入口。
- 米羊主页、账号、个人资料和证书账号入口。
- 观猹评分徽章、评价跳转和“查看全部评价”入口。
- 作者个人网站、X/Twitter 社交账号入口。
- 页尾备案信息中的外部跳转。
- 其他位于导航栏、推广区或页尾、会跳转至非本站域名的按钮型入口。

## 保留范围

- 课程正文中的论文、官方文档、技术博客、工具介绍等参考资料链接。
- 所有相对路径或同站路径的课程目录、上一页、下一页、语言切换和其他站内导航。
- 课程正文、图片、演示交互和题目数据。
- 纯展示且不触发外部跳转的作者署名、平台名称和版权信息。

## 实现方式

使用可重复的内容清理脚本识别页面位置和链接上下文，只删除导航栏、推广区、页尾及账号操作区域中的外链元素。正文参考链接不按域名批量删除，而是通过所在组件或 CSS 类限定范围，避免误伤引用内容。

清理同时应用于原始 `slides` 文件和部署目录 `public/slides`，确保本地源文件与线上构建一致。删除容器内最后一个入口后，一并移除空容器，避免页面出现无意义的留白。

## 验证

- 扫描全部 HTML 和 JavaScript，确认目标导航、推广和页尾入口不再存在。
- 抽查正文参考链接仍然存在并保持可点击。
- 检查站内相对链接未被删除。
- 完成生产构建，确认构建成功。
- 将更新后的版本发布到现有私有站点，并确认部署状态成功。

## 完成标准

网站中不再显示指定的外部平台按钮；课程正文引用和站内学习路径不受影响；五种语言页面保持一致；线上私有地址更新为新版本。
