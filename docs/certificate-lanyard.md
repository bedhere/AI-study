# 方片结业证书与双面挂绳

2026-11-10。本批开始前的版本已提交并推送到 `origin/main`，提交 `e4150b9`。以下新增开发在本地完成，未发布服务器。

## 设计与位置

沿用现有暖纸白、方片黄、墨色及真实公司 Logo。桌面首屏保留左侧课程主操作、中部机器人，在右侧增加结业证书挂绳；1439px 及以下将证书放回正常文档流，排在首屏之后、AITI 之前。减少手机拥挤，不改课程入口或人格玩法。

卡片正面为重新设计的方片结业证书，背面为素材库正式 Logo。挂绳使用本地 SVG 方片学堂纹理、金色扣件及哑光卡面；不使用原网站证书图、原网站账号标识或默认示例图片。

保留原组件的拖拽、拉伸、惯性摆动和点击翻面；提供可键盘操作的翻面按钮。取消大幅入场和持续风力，静止后停止绘制，让机器人保持主视觉。首帧未就绪或 WebGL 不可用时显示同一证书画面的静态版本，翻面按钮仍可切换；系统减少动态效果时不做物理翻转动画。

## 功能与规则

- 首页展示真实的已完成数和总数，数据来自既有 `FangpianLearning` 与当前语言的 `COURSE_FLAT`，不写入或重置学习记录。
- `certificate*.html` 展示完整证书样张、学习进度与继续学习入口；未完成所有课程时不能领取，下载按钮不可用。
- 学完当前目录的全部课程后可填写 1—24 个字的姓名，生成 `FP-日期-八位字符` 的本地编号和领取日期。
- 领取后可以修改姓名；编号和领取日期不变。取消某节课的学习标记不撤销已经领取的完成纪念，证书保留领取当时的课时数。
- 记录按语言与课程目录指纹区分，目录新增课程后不自动冒领新版本证书。其他语言的证书不会混用。
- 完整预览、3D 正面与 PNG 使用同一个绘制函数；PNG 为 2400×1706。已领取时提供标准下载链接，手机也可长按预览图片保存。
- 记录保存在 `fangpian_certificate_v1`。存储受限时保留当前页记录并说明及时保存图片；不改变原进度、考试、AITI 与虎友收集存储键。
- 当前属于依据本浏览器记录生成的内部学习纪念，未接入公司账号、云端同步、官方验证、全球排名或原站 `/auth/certificate` 接口。

原站证书的功能参考是「学完全部课程→领取→展示姓名与编号→下载 PNG」。本版本按现有本地学习能力实现，不复制原站依赖账号的流程。证书画面目前为中文，五语言入口分别读取自己的实际课程目录。

React Bits 许可为 MIT + Commons Clause，原作者为 David Haz。完整许可保存在组件目录，并嵌入发布脚本注释。Three.js 继续保留 MIT 来源与许可记录。

`npm run build:certificate` 会生成 `three-shared.js`、`robot-scene.js`、`certificate-experience.js/.css`。`predev` 与 `prebuild` 自动执行。运行时均从本站加载，不使用 React Bits CDN、模型文件或远程字体。

共享后：Three.js 约 507,709 字节（gzip 131,071），机器人约 15,797 字节，证书 React 区域约 236,304 字节（gzip 76,591）；以 SOURCE.json 的当前构建记录为准。挂绳首次进入视区才建立 WebGL 场景，离屏和页面隐藏时暂停。该预算不代表实际 FPS 测量。

## 留白与可视范围修订

按本轮截图反馈，1440px 起保留三块首屏构图：机器人投影中心由 62% 调整至 59%，相机显示比例为原来的 90%；证书移至距离右侧约 6vw 的独立区域，列宽 280—360px。右侧构图线随之移动。中等屏幕将证书排入正文，避免挤在机器人旁边。

Lanyard 新增 `overscan` 参数，首页设为 96px。画布在有足够空间时向四周扩展，并同步扩展相机视锥，保留卡片的停靠位置和清晰度。不是仅修改 CSS overflow。扩展量受视口左右安全距离限制，绘制像素仍限制在 60 万；下方说明层高于画布，翻面和领取按钮保持可点击。

1920×948 浏览器实测：证书停靠区 360×389px，实际画布约 552×581px；原版画布为 320×370px。原边界外的左上拖动已实际验证，卡片四角仍完整显示。1280px 与 375px 使用正常文档流，无横向溢出；翻面操作正常。79 项回归与生产构建通过。
