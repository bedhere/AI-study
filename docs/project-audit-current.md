## 需要优先解决的具体问题

### 1. 学习路线与结业规则尚未形成一套公司培训规则

`components/certificate/CertificateExperience.jsx` 使用完整 `COURSE_FLAT` 判断结业，简中目前是全站 442 节，包括扩展专题，而非某一条角色路线或首批培训课程。这个实现沿用了原站「学完全部课程」的方式。

需要确定：首批员工必修哪些课、三类路线各学到什么程度、证书按全站还是按路线/培训批次领取。建议先明确内部首批课程包及完成标准，再决定证书规则，避免只想学习 AI 基础的同事也必须学完全部源码与创业专题。

三类路线已有学习目标说明，可直接在此基础上补首批实操：起步者练习一次资料总结和核验；提效者练习选题/脚本/复盘等工作任务；共创者完成一个有明确输入输出和人工检查点的小工具。这些是建议样板，尚非公司已经确认的课程内容。

### 2. 首页完成度高于阅读器和课程正文

- 简中首页展示真实 442 个知识点，但 description 和分享 description 仍写 437。
- 首页及阅读器元信息仍有「AI 产品经理培训」「方片主讲」等表述，需要与全员学习定位及实际内容来源统一。
- 需求名称为「方片 AI 学堂」，当前导航等多处为「方片学堂」；应先确定正式展示名，再统一标题、导航、页脚及导出画面。
- `lesson.css` 的主要界面色仍为墨绿 `#146b54`，`exam.html` 的练习色仍为紫色 `#7c3aed`。
- AITI 顶部仍使用几何菱形标记；需在整站品牌规范中确定与正式 Logo、产品名的关系。保留 AITI 的 16 题与既有计分，不重新改回传统 MBTI 或恢复 DISC 展示入口。

下一批适合先统一公共主题、按钮、提示块和导航，再制作「知识讲解、业务实操、练习复盘」三种样板，把封面、图标、重点提示与动效一起落实。

### 3. 课程清单已有分类，内容验收还需要负责人确认

`reports/course-content-review.json` 有 2,172 条五语言记录，处理标签为「保留」2,026 条、「改写」146 条。它们不是独立中文课程数，也不是人工完成验收的数量。标记保留或改写后，仍需检查是否适合公司业务、技术事实是否准确、案例经历和来源是否清楚。

现有技术原理与必要来源可保留，优先改写公司案例、练习、旧作者经历及不适合全员培训的导向。面试、创业和源码专题属于课程定位审定对象，不应直接等同于广告/JD 残留。首批课程先定稿，再分批覆盖其余课程。

### 4. 素材优化和完整验收尚未结束

公司品牌素材已有 63 个文件，无需再次索要整套 IP。AITI 原图为 16 张 PNG、合计 11,835,811 字节，约 11.29 MiB。可生成适合列表、预览和大图的派生资源，保留用户确认的原始配色与原图。

全量静态资源存在不等于全站性能达标。仍需在目标设备和 ARP 环境检查首次加载、连续滚动、拖拽、WebGL 降级及减少动态效果；证书的原生下载落盘、移动端保存也需正式浏览器验收。社区、爸妈版等整理中内容不属于当前原始必做项，首发应整理其入口，不必为此扩建新业务。

### 5. 数据与服务仍以本地为主

学习进度、练习成绩、AITI 答案、虎友收集及证书使用浏览器存储。换浏览器、换设备或从 localhost 切换到另一个域名，记录不会自动迁移。

ARP 接入时应确认身份是否由 ARP 提供，是否需要跨设备记录，以及现有本机记录如何迁移或留存。AI 助教另需真实模型服务与服务端代理、课程上下文、流式回答和异常处理；模型凭据由服务端配置。当前页面、构建与空兼容脚本不能算这些服务已经上线。
