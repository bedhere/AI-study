# 证书全屏拖拽与机器人全页跟踪

2026-11-10。首页五种语言共用本次交互实现。

- 证书和挂绳使用独立挂载到 `body` 的全屏透明 WebGL 画布，保留右上角起始位置与原有尺寸；拖拽不再受侧栏宽度和 96px 外扩区域限制。挂绳随拖动延长，释放后逐步收回。
- 证书图形位于页面内容底层、纸色背景上方。机器人、正文、导航、按钮和弹窗处于前景。画布本身不接管整页点击，仅在命中证书且没有前景控件时启动拖拽。
- 拖拽使用指针捕获与固定深度平面。快速跨屏释放会提交最后一个指针位置，避免丢失最后一段移动；失焦、取消和隐藏页面会释放拖拽状态。
- 机器人通过页面级指针事件响应整个可视页面，包括导航区、右上角证书区与空白处；移出窗口或失焦后回到默认朝向。沿用原来的滚动淡出与减少动态效果设置。
- 窗口缩放和页面滚动会重新计算画布与证书原始位置的关系。保留窄屏布局、翻面入口、证书进度和浏览器本地数据。

## 验证

本地浏览器使用 1600×1000 桌面视口与 390×844 窄屏视口验证：桌面从 `(1338,330)` 拖到 `(290,810)`、窄屏从 `(180,145)` 拖到 `(300,680)`，实际抓取点投影与释放指针位置一致，误差小于 0.001px。释放后拖拽状态已清除；机器人与证书交叠时机器人位于上层；窄屏没有横向溢出；证书进度入口可以正常打开。浏览器错误日志为空。

上述窄屏验收使用鼠标指针，没有替代触屏真机验收。减少动态效果分支沿用原来的点击翻面方式。效果截图保存在忽略目录 `outputs/viewport-interaction/certificate-behind-robot.jpg`。
