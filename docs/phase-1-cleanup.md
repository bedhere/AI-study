## 验证方式

- `npm run check:cleanup`：扫描全部 HTML、JS、CSS 中的目标推广、JD、原站地址、动态加载和统计调用。
- `npm run verify:content`：五语言课程索引对应文件存在；对公共 JS 和全部经典内联脚本进行语法检查，明确区分基线问题与新增问题。
- `npm run build`：构建应用与静态资源。
- 浏览器抽查：首页、课程阅读器、深链及代表性课程交互；五语言首页的结构清理由全量检查覆盖。
- 浏览器实际验证：五语言首页的 JD 链接和目标推广模块均为 0，目录正常渲染；Token 词表演示由第 1/4 步成功进入第 2/4 步。
- 公司提供的 63 个 Logo/老虎文件已纳入 `public/slides/assets/fangpian`，后续按界面尺寸生成优化资源。
